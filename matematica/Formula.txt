----------------------------------------
PROGRESSÕES E SOMAS
----------------------------------------

Soma de consecutivos (PA):
  S = (primeiro + último) * n / 2

Soma de 1 até N:
  S = N * (N + 1) / 2

Soma de quadrados de 1 até N:
  S = N * (N + 1) * (2N + 1) / 6

Soma de cubos de 1 até N:
  S = (N * (N + 1) / 2)^2

Soma de PG:
  S = a * (r^n - 1) / (r - 1)  (r != 1)

Soma de PG infinita (|r| < 1):
  S = a / (1 - r)

Termo geral da PA:
  a_n = a_1 + (n - 1) * d

Termo geral da PG:
  a_n = a_1 * r^(n-1)

----------------------------------------
COMBINATÓRIA
----------------------------------------

Fatorial:
  n! = n * (n-1) * ... * 1
  0! = 1

Combinação:
  C(n, k) = n! / (k! * (n-k)!)
  C(n, 0) = C(n, n) = 1
  C(n, k) = C(n-1, k-1) + C(n-1, k)   (triângulo de Pascal)

Permutação:
  P(n, k) = n! / (n-k)!

Permutação com repetição:
  P = n! / (n1! * n2! * ... * nk!)

Arranjo:
  A(n, k) = n! / (n-k)!

Número de subconjuntos de N elementos:
  2^N

Princípio da inclusão-exclusão:
  |A ∪ B| = |A| + |B| - |A ∩ B|
  |A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|

Números de Catalan:
  C_n = C(2n, n) / (n + 1)
  C_0=1, C_1=1, C_2=2, C_3=5, C_4=14, ...
  Uso: árvores binárias, parênteses válidos, triangulações

Coeficiente binomial — identidades úteis:
  C(n, k) = C(n, n-k)
  Σ C(n, k) para k=0..n = 2^n
  Σ C(n, k)^2 para k=0..n = C(2n, n)

----------------------------------------
TEORIA DOS NÚMEROS
----------------------------------------

Divisibilidade — número de divisores:
  Se n = p1^a1 * p2^a2 * ... * pk^ak
  d(n) = (a1+1) * (a2+1) * ... * (ak+1)

Soma dos divisores:
  σ(n) = Π (p_i^(a_i+1) - 1) / (p_i - 1)

Função de Euler (totiente):
  φ(n) = n * Π (1 - 1/p)   para p primo divisor de n
  φ(1) = 1
  Se p primo: φ(p) = p - 1
  Se p primo: φ(p^k) = p^k - p^(k-1)

Pequeno Teorema de Fermat:
  a^p ≡ a (mod p)   para p primo
  a^(p-1) ≡ 1 (mod p)   para p primo e mdc(a,p)=1

Teorema de Euler:
  a^φ(n) ≡ 1 (mod n)   para mdc(a,n)=1

Inverso modular (p primo):
  a^(-1) ≡ a^(p-2) (mod p)

Teorema Chinês do Resto (CRT):
  Sistema x ≡ a_i (mod m_i) com m_i coprimos dois a dois:
  x = Σ a_i * M_i * y_i (mod M)
  onde M = Π m_i, M_i = M/m_i, y_i = M_i^(-1) (mod m_i)

MDC / MMC:
  mdc(a, b) = mdc(b, a mod b)
  mmc(a, b) = a * b / mdc(a, b)
  mdc(a, 0) = a

Identidade de Bézout:
  mdc(a, b) = a*x + b*y   (x, y inteiros)

----------------------------------------
GEOMETRIA PLANA
----------------------------------------

Distância euclidiana:
  d = sqrt((x2-x1)^2 + (y2-y1)^2)

Distância Manhattan:
  d = |x2-x1| + |y2-y1|

Área do triângulo (coordenadas):
  A = |x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2)| / 2

Produto vetorial 2D:
  (a x b) = a.x*b.y - a.y*b.x
  > 0: b está à esquerda de a (anti-horário)
  < 0: b está à direita de a (horário)
  = 0: colineares

Produto escalar:
  a · b = a.x*b.x + a.y*b.y = |a||b|cos(θ)

Área do polígono (Shoelace):
  A = |Σ (x_i * y_{i+1} - x_{i+1} * y_i)| / 2

Teorema de Pick (polígono em grade inteira):
  A = I + B/2 - 1
  I = pontos inteiros internos
  B = pontos inteiros na borda
  A = área (Shoelace)

Círculo:
  Área = π * r^2
  Perímetro = 2 * π * r

Setor circular:
  Área = θ * r^2 / 2   (θ em radianos)

Fórmula de Herão (triângulo, lados a,b,c):
  s = (a + b + c) / 2
  A = sqrt(s * (s-a) * (s-b) * (s-c))

** TRIÂNGULOS (Variações e Propriedades) **
Equilátero:
  A = (l^2 * sqrt(3)) / 4
  Altura h = (l * sqrt(3)) / 2
Com ângulo incluso:
  A = (a * b * sin(θ)) / 2
Usando Raio Inscrito (r):
  A = p * r   (p = semiperímetro)
Usando Raio Circunscrito (R):
  A = (a * b * c) / (4 * R)
Raio da Circunferência Circunscrita (Circumcircle):
  R = a / (2 * sin(A))

** POLÍGONOS REGULARES E CONVEXOS **
Soma dos ângulos internos:
  S = (n-2) * 180°
Ângulo interno (regular):
  θ_i = ((n-2) * 180°) / n
Soma dos ângulos externos:
  Sempre 360° (ou 2π radianos)
Número de diagonais:
  D = n * (n-3) / 2
Área de Polígono Regular (dado lado l):
  A = (n * l^2) / (4 * tan(π / n))

** CÍRCULOS (Arcos, Setores e Segmentos) **
Comprimento do Arco:
  L = θ * R   (θ em radianos)
  L = (θ / 360°) * 2πR   (θ em graus)
Área do Segmento Circular (fatia cortada por corda):
  A = (R^2 / 2) * (θ - sin(θ))   (θ em radianos)
Comprimento da Corda:
  C = 2 * R * sin(θ / 2)

** QUADRILÁTEROS **
Trapézio:
  A = (B + b) * h / 2
Paralelogramo:
  A = b * h   ou   A = a * b * sin(θ)
Losango:
  A = (D * d) / 2   (Diagonais maior e menor)
Quadrilátero Cíclico (Fórmula de Brahmagupta):
  A = sqrt((s-a)*(s-b)*(s-c)*(s-d))   onde s = (a+b+c+d)/2

----------------------------------------
GEOMETRIA ESPACIAL (3D)
----------------------------------------

Esfera:
  Volume = (4/3) * π * R^3
  Área da superfície = 4 * π * R^2
  Calota Esférica (Volume): V = (π * h^2 / 3) * (3R - h)   (h = altura da calota)

Cilindro:
  Volume = π * R^2 * h
  Área = 2 * π * R * (R + h)

Cone:
  Volume = (1/3) * π * R^2 * h
  Área = π * R * (R + g)   (geratriz g = sqrt(R^2 + h^2))

Tetraedro Regular (Pirâmide base triangular):
  Volume = (a^3 * sqrt(2)) / 12
  Altura = (a * sqrt(6)) / 3

----------------------------------------
TEOREMAS CLÁSSICOS
----------------------------------------

Lei dos Senos:
  a / sin(A) = b / sin(B) = c / sin(C) = 2R

Lei dos Cossenos:
  c^2 = a^2 + b^2 - 2ab*cos(C)

Teorema de Ptolomeu (Quadriláteros Cíclicos):
  a * c + b * d = d1 * d2   (lados a,b,c,d e diagonais d1,d2)

Teorema de Stewart:
  (Relação entre lados e ceviana d que divide base a em m e n)
  b^2 * m + c^2 * n = a * (d^2 + m * n)

Teorema das Bissetrizes:
  (Bissetriz divide lado oposto em segmentos proporcionais)
  x / c = y / b

----------------------------------------
ÁLGEBRA E RECORRÊNCIAS
----------------------------------------

Fórmula de Binet (Fibonacci em O(1)):
  F_n = (1 / sqrt(5)) * ( ((1 + sqrt(5))/2)^n - ((1 - sqrt(5))/2)^n )

Soma e Produto (Relações de Girard/Vieta):
  Polinômio ax^2 + bx + c = 0:
    x1 + x2 = -b / a
    x1 * x2 = c / a
  Polinômio ax^3 + bx^2 + cx + d = 0:
    x1 + x2 + x3 = -b / a
    x1*x2 + x1*x3 + x2*x3 = c / a
    x1*x2*x3 = -d / a

Desigualdade das Médias (AM-GM):
  Média Aritmética >= Média Geométrica
  (x1 + x2 + ... + xn) / n  >=  (x1 * x2 * ... * xn)^(1/n)

Soma de Progressão Aritmético-Geométrica (P.A.G.):
  Termo geral = (a + n * d) * r^n
  Dica: Multiplicar a soma S por r e resolver S - r*S = ...

Exponenciação de Matrizes:
  Toda recorrência f(n) = a*f(n-1) + b*f(n-2) + c pode ser calculada em O(log n)
  elevando a matriz de transição de estados à potência n.

----------------------------------------
TEORIA DOS GRAFOS
----------------------------------------

Handshaking lemma:
  Σ grau(v) = 2 * |E|

Árvore com N vértices:
  |E| = N - 1

Grafo euleriano (não direcionado):
  Circuito: todos os graus pares + conexo
  Caminho: exatamente 2 vértices de grau ímpar + conexo

Grafo euleriano (direcionado):
  Circuito: in[v] = out[v] para todo v + conexo
  Caminho: um v com out-in=1 (início), um com in-out=1 (fim), resto iguais

Fórmula de Euler (grafo planar):
  V - E + F = 2   (V vértices, E arestas, F faces incluindo externa)

----------------------------------------
PROBABILIDADE
----------------------------------------

Probabilidade condicional:
  P(A|B) = P(A ∩ B) / P(B)

Teorema de Bayes:
  P(A|B) = P(B|A) * P(A) / P(B)

Valor esperado:
  E[X] = Σ x_i * P(x_i)
  E[aX + b] = a*E[X] + b
  E[X + Y] = E[X] + E[Y]

Variância:
  Var(X) = E[X^2] - E[X]^2

----------------------------------------
EXPONENCIAÇÃO E LOGARITMOS
----------------------------------------

Exponenciação rápida:
  a^n em O(log n) por repeated squaring

Identidades de log:
  log(a*b) = log(a) + log(b)
  log(a/b) = log(a) - log(b)
  log(a^b) = b * log(a)
  log_b(a) = log(a) / log(b)

Número de dígitos de N na base B:
  d = floor(log_B(N)) + 1

----------------------------------------
BITMASK
----------------------------------------

Número de subconjuntos de N elementos:
  2^N

Soma de todos os tamanhos de subconjuntos:
  N * 2^(N-1)

----------------------------------------
STRINGS
----------------------------------------

Número de substrings de string de tamanho N:
  N * (N + 1) / 2

----------------------------------------
MISCELÂNEA
----------------------------------------

Princípio das casas de pombo (Pigeonhole):
  N+1 objetos em N caixas → alguma caixa tem >= 2 objetos

Soma dos primeiros N ímpares:
  1 + 3 + 5 + ... + (2N-1) = N^2

Potências de 2:
  2^10 = 1.024    (~10^3)
  2^20 = 1.048.576  (~10^6)
  2^30 = 1.073.741.824 (~10^9)

Limite int (32 bits):
  INT_MAX =  2^31 - 1 =  2.147.483.647  (~2*10^9)
  INT_MIN = -2^31   = -2.147.483.648

Limite long long (64 bits):
  LLONG_MAX =  2^63 - 1  (~9.2*10^18)
  LLONG_MIN = -2^63    (~-9.2*10^18)
