----------------------------------------
PROGRESSÕES E SOMAS
----------------------------------------

Soma de consecutivos (PA):
  S = (primeiro + último) * n / 2

Soma de 1 até N:
  S = N * (N + 1) / 2

Soma de quadrados de 1 até N:
  S = N * (N + 1) * (2N + 1) / 6

Soma de cubos de 1 até N:
  S = (N * (N + 1) / 2)^2

Soma de PG:
  S = a * (r^n - 1) / (r - 1)  (r != 1)

Soma de PG infinita (|r| < 1):
  S = a / (1 - r)

Termo geral da PA:
  a_n = a_1 + (n - 1) * d

Termo geral da PG:
  a_n = a_1 * r^(n-1)

----------------------------------------
COMBINATÓRIA
----------------------------------------

Fatorial:
  n! = n * (n-1) * ... * 1
  0! = 1

Combinação:
  C(n, k) = n! / (k! * (n-k)!)
  C(n, 0) = C(n, n) = 1
  C(n, k) = C(n-1, k-1) + C(n-1, k)   (triângulo de Pascal)

Permutação:
  P(n, k) = n! / (n-k)!

Permutação com repetição:
  P = n! / (n1! * n2! * ... * nk!)

Arranjo:
  A(n, k) = n! / (n-k)!

Número de subconjuntos de N elementos:
  2^N

Princípio da inclusão-exclusão:
  |A ∪ B| = |A| + |B| - |A ∩ B|
  |A ∪ B ∪ C| = |A| + |B| + |C| - |A∩B| - |A∩C| - |B∩C| + |A∩B∩C|

Números de Catalan:
  C_n = C(2n, n) / (n + 1)
  C_0=1, C_1=1, C_2=2, C_3=5, C_4=14, ...
  Uso: árvores binárias, parênteses válidos, triangulações

Coeficiente binomial — identidades úteis:
  C(n, k) = C(n, n-k)
  Σ C(n, k) para k=0..n = 2^n
  Σ C(n, k)^2 para k=0..n = C(2n, n)

Números de Stirling (segunda espécie):
  S(n, k) = número de formas de particionar n elementos em k grupos não vazios
  S(n, k) = k*S(n-1, k) + S(n-1, k-1)

Números de Bell:
  B_n = número total de partições de um conjunto de n elementos
  B_n = Σ S(n, k) para k=0..n

Derangements (permutações sem ponto fixo):
  D(n) = (n-1) * (D(n-1) + D(n-2))
  D(n) = n! * Σ (-1)^k / k!  para k=0..n
  D(0)=1, D(1)=0, D(2)=1, D(3)=2, D(4)=9

Lema de Burnside:
  |X/G| = (1/|G|) * Σ |Fix(g)|  para g em G

----------------------------------------
TEORIA DOS NÚMEROS
----------------------------------------

Divisibilidade — número de divisores:
  Se n = p1^a1 * p2^a2 * ... * pk^ak
  d(n) = (a1+1) * (a2+1) * ... * (ak+1)

Soma dos divisores:
  σ(n) = Π (p_i^(a_i+1) - 1) / (p_i - 1)

Função de Euler (totiente):
  φ(n) = n * Π (1 - 1/p)   para p primo divisor de n
  φ(1) = 1
  Se p primo: φ(p) = p - 1
  Se p primo: φ(p^k) = p^k - p^(k-1)
  Σ φ(d) para d divisor de n = n

Pequeno Teorema de Fermat:
  a^p ≡ a (mod p)   para p primo
  a^(p-1) ≡ 1 (mod p)   para p primo e mdc(a,p)=1

Teorema de Euler:
  a^φ(n) ≡ 1 (mod n)   para mdc(a,n)=1

Inverso modular (p primo):
  a^(-1) ≡ a^(p-2) (mod p)

Teorema Chinês do Resto (CRT):
  Sistema x ≡ a_i (mod m_i) com m_i coprimos dois a dois:
  x = Σ a_i * M_i * y_i (mod M)
  onde M = Π m_i, M_i = M/m_i, y_i = M_i^(-1) (mod m_i)

MDC / MMC:
  mdc(a, b) = mdc(b, a mod b)
  mmc(a, b) = a * b / mdc(a, b)
  mdc(a, 0) = a

Identidade de Bézout:
  mdc(a, b) = a*x + b*y   (x, y inteiros)

Teorema de Wilson:
  (p-1)! ≡ -1 (mod p)   se e somente se p é primo

Teorema de Wolstenholme:
  Para p primo >= 5, C(2p, p) ≡ 2 (mod p^3)

Contagem de primos até N (aproximação, Teorema dos Números Primos):
  π(N) ≈ N / ln(N)

Fórmula de Legendre (expoente de p em n!):
  e_p(n!) = Σ floor(n / p^k) para k=1,2,3,...

----------------------------------------
GEOMETRIA
----------------------------------------

Distância euclidiana:
  d = sqrt((x2-x1)^2 + (y2-y1)^2)

Distância Manhattan:
  d = |x2-x1| + |y2-y1|

Distância Chebyshev:
  d = max(|x2-x1|, |y2-y1|)

Área do triângulo (coordenadas):
  A = |x1*(y2-y3) + x2*(y3-y1) + x3*(y1-y2)| / 2

Produto vetorial 2D:
  (a x b) = a.x*b.y - a.y*b.x
  > 0: b está à esquerda de a (anti-horário)
  < 0: b está à direita de a (horário)
  = 0: colineares

Produto escalar:
  a · b = a.x*b.x + a.y*b.y = |a||b|cos(θ)

Área do polígono (Shoelace):
  A = |Σ (x_i * y_{i+1} - x_{i+1} * y_i)| / 2

Teorema de Pick (polígono em grade inteira):
  A = I + B/2 - 1
  I = pontos inteiros internos
  B = pontos inteiros na borda
  A = área (Shoelace)

--- Triângulos ---

Área (base x altura):
  A = base * altura / 2

Fórmula de Herão (lados a,b,c):
  s = (a + b + c) / 2
  A = sqrt(s * (s-a) * (s-b) * (s-c))

Área via lei dos senos:
  A = (a * b * sin(C)) / 2

Lei dos cossenos:
  c^2 = a^2 + b^2 - 2*a*b*cos(C)

Lei dos senos:
  a/sin(A) = b/sin(B) = c/sin(C) = 2R
  (R = raio do circuncírculo)

Triângulo isósceles (lados iguais L, base B):
  altura h = sqrt(L^2 - (B/2)^2)
  A = B * h / 2

Triângulo equilátero (lado L):
  A = (sqrt(3)/4) * L^2
  altura h = (sqrt(3)/2) * L

Raio do incírculo:
  r = A / s   (s = semiperímetro)

Raio do circuncírculo:
  R = (a * b * c) / (4 * A)

Centroide:
  G = ((x1+x2+x3)/3, (y1+y2+y3)/3)

Soma dos ângulos internos de um triângulo:
  180°

--- Polígonos ---

Soma dos ângulos internos de um polígono de N lados:
  S = (N - 2) * 180°

Ângulo interno de polígono regular de N lados:
  a = (N - 2) * 180° / N

Ângulo externo de polígono regular:
  360° / N

Área de polígono regular (lado L, N lados):
  A = (N * L^2) / (4 * tan(π/N))

Apótema de polígono regular:
  ap = L / (2 * tan(π/N))

Área de polígono regular (via apótema e perímetro):
  A = ap * perímetro / 2

Diagonais de um polígono de N lados:
  D = N * (N - 3) / 2

--- Quadriláteros ---

Retângulo:
  A = base * altura
  Diagonal = sqrt(base^2 + altura^2)

Quadrado (lado L):
  A = L^2
  Diagonal = L * sqrt(2)

Losango (diagonais d1, d2):
  A = d1 * d2 / 2

Trapézio (bases b1, b2, altura h):
  A = (b1 + b2) * h / 2

Fórmula de Brahmagupta (quadrilátero cíclico, lados a,b,c,d):
  s = (a+b+c+d)/2
  A = sqrt((s-a)*(s-b)*(s-c)*(s-d))

--- Círculo ---

Área:
  A = π * r^2

Perímetro (circunferência):
  C = 2 * π * r

Setor circular (ângulo θ em radianos):
  Área = θ * r^2 / 2
  Comprimento do arco = θ * r

Segmento circular (ângulo θ em radianos):
  Área = r^2 * (θ - sin(θ)) / 2

Comprimento de corda (ângulo central θ):
  L = 2 * r * sin(θ/2)

Área entre duas circunferências concêntricas (coroa circular):
  A = π * (R^2 - r^2)

Potência de um ponto em relação a um círculo:
  pot = d^2 - r^2   (d = distância do ponto ao centro)

--- Sólidos (área e volume) ---

Cubo (aresta a):
  V = a^3
  A_total = 6*a^2

Paralelepípedo (a,b,c):
  V = a*b*c
  A_total = 2*(ab + bc + ac)

Esfera (raio r):
  V = (4/3) * π * r^3
  A_total = 4 * π * r^2

Cilindro (raio r, altura h):
  V = π * r^2 * h
  A_lateral = 2 * π * r * h
  A_total = 2*π*r*h + 2*π*r^2

Cone (raio r, altura h, geratriz g = sqrt(r^2+h^2)):
  V = π * r^2 * h / 3
  A_lateral = π * r * g
  A_total = π*r*g + π*r^2

Pirâmide (área da base Ab, altura h):
  V = Ab * h / 3

Prisma (área da base Ab, altura h):
  V = Ab * h

Tronco de cone (raios R, r, altura h):
  V = (π * h / 3) * (R^2 + R*r + r^2)

--- Geometria analítica / vetores ---

Ponto médio:
  M = ((x1+x2)/2, (y1+y2)/2)

Equação da reta (dois pontos):
  (y - y1) / (y2 - y1) = (x - x1) / (x2 - x1)

Distância de ponto a reta (ax+by+c=0):
  d = |a*x0 + b*y0 + c| / sqrt(a^2 + b^2)

Interseção de segmentos:
  usar orientação (produto vetorial) para checar se os segmentos se cruzam

Norma de um vetor:
  |v| = sqrt(v.x^2 + v.y^2)

Ângulo entre dois vetores:
  cos(θ) = (a·b) / (|a|*|b|)

Rotação de ponto (θ radianos, em torno da origem):
  x' = x*cos(θ) - y*sin(θ)
  y' = x*sin(θ) + y*cos(θ)

Fecho convexo (Convex Hull) — Teorema:
  Complexidade ótima O(n log n) (ex: Graham Scan, Andrew's Monotone Chain)

----------------------------------------
TEOREMAS ÚTEIS DIVERSOS
----------------------------------------

Teorema de Pitágoras:
  a^2 + b^2 = c^2   (c = hipotenusa)

Teorema de Tales:
  retas paralelas cortadas por transversais formam segmentos proporcionais

Teorema da Bissetriz Interna:
  divide o lado oposto em segmentos proporcionais aos lados adjacentes

Teorema de Ceva:
  (AF/FB) * (BD/DC) * (CE/EA) = 1   (cevianas concorrentes)

Teorema de Menelaus:
  (AF/FB) * (BD/DC) * (CE/EA) = -1  (pontos colineares em transversal)

Teorema de Stewart (triângulo com ceviana d até lado a, dividindo-o em m e n):
  b^2*m + c^2*n - d^2*a = a*m*n

----------------------------------------
TEORIA DOS GRAFOS
----------------------------------------

Handshaking lemma:
  Σ grau(v) = 2 * |E|

Árvore com N vértices:
  |E| = N - 1

Grafo euleriano (não direcionado):
  Circuito: todos os graus pares + conexo
  Caminho: exatamente 2 vértices de grau ímpar + conexo

Grafo euleriano (direcionado):
  Circuito: in[v] = out[v] para todo v + conexo
  Caminho: um v com out-in=1 (início), um com in-out=1 (fim), resto iguais

Fórmula de Euler (grafo planar):
  V - E + F = 2   (V vértices, E arestas, F faces incluindo externa)

Número máximo de arestas em grafo planar simples (N>=3):
  E <= 3N - 6

Teorema de Kirchhoff (número de árvores geradoras):
  via matriz Laplaciana, teorema da árvore geradora (Matrix-Tree Theorem)

----------------------------------------
PROBABILIDADE
----------------------------------------

Probabilidade condicional:
  P(A|B) = P(A ∩ B) / P(B)

Teorema de Bayes:
  P(A|B) = P(B|A) * P(A) / P(B)

Valor esperado:
  E[X] = Σ x_i * P(x_i)
  E[aX + b] = a*E[X] + b
  E[X + Y] = E[X] + E[Y]

Variância:
  Var(X) = E[X^2] - E[X]^2

Linearidade da esperança:
  vale mesmo se X e Y não forem independentes

----------------------------------------
EXPONENCIAÇÃO E LOGARITMOS
----------------------------------------

Exponenciação rápida:
  a^n em O(log n) por repeated squaring

Identidades de log:
  log(a*b) = log(a) + log(b)
  log(a/b) = log(a) - log(b)
  log(a^b) = b * log(a)
  log_b(a) = log(a) / log(b)

Número de dígitos de N na base B:
  d = floor(log_B(N)) + 1

----------------------------------------
MISCELÂNEA
----------------------------------------

Princípio das casas de pombo (Pigeonhole):
  N+1 objetos em N caixas → alguma caixa tem >= 2 objetos

Soma dos primeiros N ímpares:
  1 + 3 + 5 + ... + (2N-1) = N^2

Potências de 2:
  2^10 = 1.024    (~10^3)
  2^20 = 1.048.576  (~10^6)
  2^30 = 1.073.741.824 (~10^9)

Limite int (32 bits):
  INT_MAX =  2^31 - 1 =  2.147.483.647  (~2*10^9)
  INT_MIN = -2^31   = -2.147.483.648

Limite long long (64 bits):
  LLONG_MAX =  2^63 - 1  (~9.2*10^18)
  LLONG_MIN = -2^63    (~-9.2*10^18)
